● SOLO LECTURA

Lee datos. No abre, modifica ni cierra operaciones.

El puente expone únicamente funciones de lectura de la API oficial de Python de MetaTrader 5. La única función de ejecución de esa API (order_send) nunca se expone.

  • Sin ejecución de órdenes (allowlist de solo lectura)
  • Transporte local por stdio — sin puertos de red abiertos
  • Empieza siempre con cuenta demo
  • Credenciales solo en variables de entorno locales, nunca en archivos versionados
  • Sin señales, sin bots, sin trading automático
  • Tus datos no salen de tu máquina salvo consentimiento explícito

FAQ

¿Necesito el Pro para usar los 15 agentes?
No. Los 15 agentes están completos en el Core (9,49€). El Pro añade el MT5 Bridge Playbook para conectar MetaTrader 5 y dejar de exportar a mano.
¿La IA opera por mí?
No. El puente es de solo lectura: no abre, no modifica y no cierra operaciones. No hay señales ni trading automático.
¿Es un producto oficial de MetaTrader o MetaQuotes?
No. Es un adaptador MCP local basado en la API oficial de Python de MetaTrader 5. No es un producto de MetaQuotes ni está asociado a ellos.
¿El puente sustituye el análisis por archivos?
No del todo. Para auditar el informe de un backtest (.htm), una optimización o el código MQL sigues aportando esos archivos. El puente brilla en datos en vivo y en calidad de datos.
¿Funciona en Mac?
MetaTrader 5 y su API de Python funcionan en Windows. En Mac se documenta la vía mediante una VM o VPS Windows. No prometemos soporte nativo de macOS.

Compatibilidad del puente: Windows · Python · MetaTrader 5 Desktop · Claude Code (validado). Soporte de Codex para el puente: pendiente de validar. En macOS, mediante VM/VPS Windows. La guía Pro fija la versión del servidor probada, el SO y la versión de Python usados.
